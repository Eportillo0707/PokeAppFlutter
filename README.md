# PokeAPP Flutter

Migracion Flutter de `Eportillo0707/PokeAPP`, orientada a Android y iOS.

## Funcionalidad portada

- Listado paginado de Pokemon usando PokeAPI.
- Busqueda por nombre.
- Filtro por tipo.
- Pantalla de favoritos persistidos localmente.
- Detalle con imagen oficial, tipos, estadisticas, descripcion, habilidades, cadena evolutiva y mega evoluciones.
- Pestana de movimientos adaptada a telefonos con botones Por nivel, MT y Train,
  filtros desplegables de juego, tipos disponibles y categoria. Muestra tipo,
  categoria, potencia y precision, y abre una ficha con PP, generacion y descripcion.
  Utiliza los datos de
  movimientos de la respuesta del Pokemon. Consulta las maquinas de los movimientos
  mostrados para identificar MT, MO o DT segun el juego, con cache en memoria.
