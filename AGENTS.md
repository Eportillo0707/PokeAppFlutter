# Reglas del proyecto

- Ningún archivo de código nuevo o modificado debe superar las 100 líneas.
- Si un archivo existente ya supera las 100 líneas y necesitas modificarlo, divídelo en archivos más pequeños como parte del mismo cambio. Conserva su comportamiento.
- Antes de dar una tarea por terminada, cuenta las líneas de todos los archivos de código modificados y confirma que cada uno tiene 100 o menos.
- Si no puedes cumplir el límite sin perjudicar el diseño o el funcionamiento, explícalo antes de dar la tarea por terminada. No declares que se cumplió la regla.
